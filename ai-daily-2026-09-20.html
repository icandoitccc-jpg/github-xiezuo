Claude Code 重推 Projects：一个对话框，带出一支云端线程团队

AI Coding / 智能体编排

9 月 17 日 Anthropic 官宣重新设计的 Projects 功能，第一站直接落在 Claude Code，随后两日在中文圈持续发酵。架构分两层：上层是项目对话，Claude 充当协调者——判断需求该拆成几块、派给新线程还是已在干相关活的线程、最后审查结果组装成品；下层是线程——每条都是独立的 Claude Code 云端会话，有自己的上下文、Git 分支和代码副本，可以各自开 PR、跑测试，冲突按普通 PR 合并逻辑处理。你合上笔记本它们还在跑，需要拍板时它会回来找你。

关键参数：每项目每天最多 200 条新线程；项目内共享记忆文件与跨线程资料库；总览面板按状态分组；Beta 先面向部分 Pro/Max 云端会话用户。配套的 Claude Code 2.1.278（9/19）把 auto mode 的安全检查/模型路由分类器默认搬到 Anthropic 服务端运行，这一步自身的 token 开销不再计费——用省下的分类费换用户留在托管运行时里。至此，从 4 月桌面端多窗口并排、Routines 定时任务、6 月 Claude Tag 进 Slack，到 Projects 接管调度，Anthropic 把"托管式多智能体开发"的拼图补完了。

Why it matters：Claude Code 的形态正在质变：从"一个终端会话"变成"一支云端线程团队"，协调者—线程分工把项目经理的活也接了过去。更微妙的是，token 消耗的决定权从写指令的人手里挪到了卖 token 的一方——每项目每天 200 条线程的上限本身就是一道用量闸门。coding agent 的竞争由此从"模型多强"进入"编排与托管运行时"阶段，OpenAI/Cursor 的对应产品如何回应，将是 Q4 的关键看点。

Hacktron"HEIF Heist"：用 Claude Opus 5 三小时打穿 OpenAI，两月研究 AI 成本不到 3000 美元

AI Coding / 智能体安全

9 月 18 日，安全公司 Hacktron 公布研究"HEIF Heist"：三名研究员借 Anthropic 的 Claude Opus 5，从 OpenAI 公开帮助论坛一路走进内部代码仓库，从发现漏洞到拿到内部仓库访问权不到 72 小时——全程没有钓鱼、没有偷密码。入口是图片解码：OpenAI 社区论坛托管在 Discourse 上，经 ImageMagick 调 libheif 处理 HEIC/HEIF 上传，而 Debian 包缺少上游安全补丁，存在堆缓冲区溢出（CVE-2026-32882）；转折点是 SSO——拿下论坛后串上 OpenAI 单点登录的信任边界问题，接管员工 ChatGPT 与 Codex 账户，其中一个 Codex 账户连着 OpenAI 的 GitHub 组织，他们用一个无害 PR 打进 openai/openai 私有 monorepo 证明访问成功（未读源码、未合并）。

真正的新变量是模型换代带来的成本坍塌：上一代 Opus 4.8 卡在 ASLR 等防护上难以产出稳定利用，Opus 5 发布后约 3 小时就产出可用 exploit；两个月全线研究（横跨 Slack、Meta、GitHub Enterprise、Next.js 等目标）AI 使用成本合计不到 3000 美元。OpenAI 在收到报告后约 14 小时完成修复并支付 6,500 美元赏金；Discourse 次周一发布补丁并为图片处理加沙箱。Hacktron 的结论：问题不只在某个图片库，OpenAI 的 SSO 信任架构才是关键——任何接入 OpenAI SSO 的三方服务被攻破都可能引发类似横向移动。

Why it matters：与上周 Plugin4Shell（"供给 Agent 的管道"被投毒）相对，这次是"Agent 自身成为攻击杠杆"。防御方接下来要重新计算的是"利用一个内存破坏漏洞"的市场价格——当模型换代能把 exploit 开发周期从"做不出来"压缩到 3 小时、成本压到千美元级，传统"漏洞难利用=相对安全"的假设开始失效。对企业的直接启示：SSO 信任边界审查、开源依赖补丁 backport 时效、以及 AI 参与渗透测试的授权边界，都需要重新梳理。

法拉第未来"告别造车"：919 发布会一口气推出 9 款 EAI 机器人，发布即交付

Embodied Intelligence / 车企跨界

9 月 20 日，Faraday Future（NASDAQ: FFAI）举办"919 FF EAI 机器人四核全智"发布会，标志着这家公司从电动车企业正式转向 Embodied AI 生态。本次发布覆盖人形与四足两大形态、Futurist / Master / Aegis 三大系列、五大型号共九款配置，建议零售价 9,990–137,900 美元，发布即上市销售并开启交付。旗舰 All-New Futurist 身高约 173cm、全身 31 自由度、续航 6 小时、售价 89,900 美元，是全美首款原生适配 NVIDIA Sonic 全尺寸人形运控系统的本体；Master Mini 起售价 9,990 美元，是北美首款万元以下、兼具编程教育/开放开发/运动竞技的紧凑型人形。发布会同时推出 K-12 教育、科研、安防、巡检四套行业方案，技术底座为自研"一脑多形"通用 EAI 大脑（VLA + 世界模型）。

Why it matters：继小鹏、特斯拉、奇瑞、比亚迪等车企下场后，又一家知名企业把战略重心整体押注具身智能，"跨界造人"从概念走成事实。"一脑多形 / 多形多能"路线与宇树、智元、松延等国内厂商收敛中的 VLA + 世界模型范式一致，说明具身智能的竞争焦点已明确转向"统一大脑 + 多本体适配"；同时北美万元以下人形的出现，可能重写海外消费级机器人定价体系。车企集体转型也与国内"量产元年 + 900 亿融资"的产业底色形成供需共振。

宇树开源 UnifoLM-WLA-1.0：6B 参数具身大脑，一个模型跑通 64 项真实物理任务

Embodied Intelligence / 开源基础模型

9 月 20 日，宇树科技发布通用人形机器人基础模型 UnifoLM-WLA-1.0。WLA 即 World-Language-Action：把环境感知、语义理解、空间推理、动态预测和动作生成放进同一个神经网络——机器人不再是"先看→再想→再动"的三段式流水线，而是感知—预测—动作的毫秒级闭环。仅用 6B 参数横跨 64 项真实物理任务：54 项精细桌面操作（端茶倒水、开关抽屉、拧瓶盖）+ 10 项全身协调运动（上下台阶、跨越障碍、单脚站立）。它也不挑硬件：既兼容低成本二指夹爪，也原生支持 Shadow Dexterous Hand、Allegro Hand 等主流五指灵巧手。

能力侧，其具身推理底座 UnifoLM-ER-1-4B 在 16 项多模态基准的 RefSpatial-Bench、Where2Place、PixMo-Point、BLINK、EmbSpatial、RoboSpatial、VSR 等 7 大空间理解类榜单上全部拿下开源模型第一（厂商口径，称已逼近闭源模型水准）。更重要的是开放程度：权重、代码、训练框架/数据集全量开源，而不只是"开源权重"。

Why it matters：这是国内头部本体厂第一次把"具身大脑"以权重+代码+数据的全量方式开源，直接对峙 Gemini Robotics、π 系列等闭源路线。过去人形机器人"偏科"严重——走路一套策略、抓取另一套，每个动作单独调参；统一模型 + 跨本体适配（连灵巧手型号都不锁死）正是行业收敛中的"大脑革命"方向。开源会加速中小团队复用，把竞争从"本体价格战"推向"大脑生态战"——谁的开源大脑被更多本体跑起来，谁就掌握具身智能的"Android 时刻"入场券。

启元 Q1/T1 消费级人形正式开售：2.1 亿预收款，"本体 + Agent 生态"成新分工范式

Embodied Intelligence / 消费级商业化

同日（9 月 20 日），上纬新材旗下启元机器人在上海西岸梦中心举行"我和我的个人机器人"发布会，88cm 的启元 Q1 与可变形的启元 T1 正式亮相并发售。据行业媒体报道，两款产品预收款已达 2.1 亿元，对应万台级产线——消费级人形机器人第一次以这种规模"摆上货架"。产品差异化不在参数表，而在生态分工：启元 Q1 顶部集成腾讯 WorkBuddy 作为"大脑"，用户用自然语言即可调用上万种智能技能、为机器人编排跳舞唱歌等动作——本体负责感知与执行，智能与技能由云端 Agent 生态供给；与飞阔科技的共建则让它"握手约 1 分钟"即可通过 PPG 脉搏波完成心率、血氧、体温采集，健康监测自然融入人机互动。

学术侧的绑定同样密集：清华大学 RoboCup 冠军团队核心成员创立的弦动光年与启元合作，8 月在 CMG 机器人挑战赛上由 Q1 独立完成定位、助跑射门、守门扑救整套动作；北大计算机学院董豪教授出任首席科学家，联合研究成果 NavSpace 已被 ICRA 2026 收录。高校负责算法边界探索、企业输出开放平台与标准化量产本体的模式，正在成为消费级具身智能公司的标准打法。

Why it matters：消费级人形从"发布会 PPT"走向"货架 SKU"，2.1 亿预收款若兑现，将是 C 端人形机器人迄今最大规模的真金白银验证。"本体 + 大模型 Agent 生态"的分工给出消费级落地的另一条路径：不追求本体出厂即全能，而是让云端 Agent 生态持续供给技能——这与法拉第未来的"一脑多形"、宇树的"开源大脑"共同指向同一个判断：2026 年具身智能的胜负手已从硬件参数转向"大脑 + 生态 + 交付"的体系能力。
