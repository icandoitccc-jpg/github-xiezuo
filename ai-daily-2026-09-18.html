四大主流编程代理 Skills 自动更新机制被曝同源漏洞：Claude Code、Codex、Gemini CLI、Copilot "一锅端"

AI Coding / 供应链安全

9 月 18 日凌晨，网络安全初创公司 Air 独家披露：全球最主流的四款 AI 编程代理——Claude Code、OpenAI Codex、Google Gemini CLI、GitHub Copilot——存在同一个逻辑缺陷。问题出在"技能（Skills）插件"的自动更新机制上：更新技能包时不校验内容变更，攻击者只需制作与正版同名的恶意更新包即可绕过扫描，混入开发环境；得手后可借 AI 代理的代码仓库权限静默窃取源代码、API 密钥、内部文档，甚至触及生产环境。修复进度：Claude Code、Codex、Gemini CLI 三家已打补丁，GitHub 仅回应"平台机制可阻断此类攻击"，未明确确认补丁状态。

背景是这条安全线近期已连续出事：恶意 VS Code 插件累计安装超 150 万次、有人向 AI 技能市场一次性灌入 800 多个恶意技能包、Claude Code 曾被曝 API 密钥窃取漏洞（CVE-2026-21852）。政策端同步收紧：9 月 14 日全国网安标委发布《人工智能安全治理框架 3.0》专门划出智能体风险红线，四天内三次高层动作。

Why it matters：这是"技能包生态"成为行业标准后暴露的第一批结构性风险——四家头部厂商在同一环节犯同一个错，说明 skills 自动更新已是被普遍复制的默认设计，而它的攻击面（供应链投毒 + Agent 天然持有仓库级权限）比传统插件生态更致命。对重度使用编程代理的团队，实操结论很具体：技能包来源收敛到可信清单、更新走人工确认而非静默自动，别让 Agent 同时持有"装包"和"读仓库"两类权限。这也预示企业级 Agent 部署将把"技能包审计"纳入合规项，安全工具链会是 coding 基础设施的下一个增量市场。

AI Agents 大规模 Rust 重写潮：GitHub 80 万行 Copilot runtime、Bun 50 万行 Zig 11 天迁移、OpenAI Habitat CPU 降 6 倍

AI Coding / 工程范式

"AI agents 干大型语言迁移"本周从个案变成了现象级范式，三个头部案例同期披露：

GitHub：用 Copilot coding agents 把 Copilot agent runtime 从 TypeScript/Node.js 完整重写为 80 万+ 行生产级 Rust——主要由一名开发者在几个月内完成（128 个 PR 增量交付、边迁边发），微软工程师估算无 Agent 需要团队 1–2 年；Anthropic：收购 Bun 后用预发布 Claude 模型，11 天把 50 万+ 行 Zig 重写为 Rust（动因是持续的内存管理 bug），打法是多 Claude Code Agent 并行、一次到位（all-at-once），创始人 Jarred Sumner 监控并按需介入；OpenAI：用 Codex + GPT-5.5 把存储服务 Habitat 从 Python 重写为 Rust，95% 生产请求 CPU 降 6 倍、内存降 15 倍。此外 Meta 的 React Compiler 也在由 AI 占多数编码迁移到 Rust（人类只管架构与策略）。

Why it matters："重写一门语言的存量代码库"过去是工程上被判定为不划算的禁区（数年人力、引入回归风险），现在三个最懂 Agent 的公司不约而同用 Agent 突破了它，且给出了两条可复制打法：增量式（GitHub，128 PR 边迁边发）vs 一次性并行迁移（Bun，多 Agent 同步翻译互检）。更深的信号是：软件维护的最大存量成本——"能跑但没人敢动的老代码"——第一次变成了 Agent 的相对优势区（人类怕改错，Agent 可以全量重跑测试验证）。性能与内存安全收益（6 倍 CPU / 15 倍内存）还顺带回答了"AI 写的代码质量行不行"：在迁移这种可机械化验证的任务上，答案已经接近"行"。

AI Coding 开源生态双信号：阿里 open-code-review 登顶 Trending（token 消耗 1/9）+ Osmani agent-skills 冲到 9.5 万星

AI Coding / 开源与技能层标准化

阿里 open-code-review 登上 GitHub Trending（3 万+ Star、Apache-2.0），官方称"在阿里规模实战验证"。看点在架构：确定性流水线（静态检查/规则/依赖）兜底 + LLM Agent 只处理语义与上下文的混合模式——官方数据是单 PR 审查 token 消耗约为纯 LLM 方案的 1/9，且精度优先策略下漏报率更低。同日，前 Google Chrome 工程负责人 Addy Osmani 的 agent-skills 仓库冲到 9.5 万+ Star，把资深工程师的隐性经验（code review 纪律、测试严谨性、调试启发式、API 设计模式）打包成跨模型可加载的技能定义（OpenAI/Anthropic/开源权重模型通用）。腾讯 BrowserSkill（Agent 操作真实登录态浏览器）、alphaXiv OpenResearch（编码 Agent 转研究 Agent）同期跟进，"技能层"正在成为事实标准。

Why it matters：两条开源热榜殊途同归，指向同一件事：Agent 竞争的主战场正从"模型多聪明"下沉到"工程纪律如何被编码与复用"。open-code-review 的混合架构是对"Agent 评审不可信、token 贵"两个行业痛点的正面回答——机器确定性管 80% 的机械问题，模型只花预算在语义层，1/9 的成本差会倒逼所有代码审查工具重写架构；agent-skills 的爆发则说明团队开始把"资深工程师的判断力"资产化为可版本管理、可跨模型移植的技能包，谁先沉淀领域技能库，谁就握住了工作流的定义权（类似 React/Kubernetes 生态重力井的路径）。对自建工具链的团队，"把高频 SOP 写成 skill"是当下性价比最高的 Agent 优化动作。

Agility 发布 Digit 5：无安全笼协作人形 + 超 3 亿美元订单；英国 Humanoid 3.4 万台预订单——海外工业需求"双验证"

Embodied Intelligence / 商业化里程碑

Agility Robotics 发布 Digit 5：首款无需安全保护笼即可在人类环境中作业的双足人形机器人，覆盖拆垛、配货、码垛等仓库环节，公司称已锁定超 3 亿美元的多年期订单，2027 年上半年开始交付早期版本。同日另一条验证来自英国：Humanoid（英国）披露累计 3.4 万台预订单——该公司 7 月刚完成 1.52 亿美元 A 轮（投后 13.5 亿美元，欧洲首家纯人形机器人独角兽），并与 Schaeffler 签有数千台规模化部署协议。加上特斯拉中国供应链审厂加速 Optimus 量产，工业侧的真实需求信号在本周密集出现。

"无笼"是个被低估的技术门槛：有安全笼意味着机器人只能被隔离在固定区域，无笼则要求机器人具备对人类的实时感知、预测与规避能力——这是它从"封闭产线设备"变成"人类工作流同事"的分界线。

Why it matters：人形机器人讨论了两年"什么时候商业化"，本周海外给出的答案是：订单先于完美——Digit 5 的 3 亿美元多年期订单和 Humanoid 的 3.4 万台预订单都是客户在交付前用真金白银下的注，物流仓储已成为被验证的第一落地场景（与国内顺丰-寅成智能亿元订单、优必选柳州工厂形成中美同步）。行业筛选逻辑随之可操作化：判断具身智能公司的成熟度，看三个硬指标——是否有无笼协作能力、是否有可对账的多年期订单、交付时间是否给出明确季度。2027 上半年（Digit 5 交付）将是大批量人形机器人进入真实工作流的首个大考节点。

Embodied Intelligence / 基础设施与资本

9 月 17 日，地瓜机器人（地平线机器人事业部 2024 年初拆分组建）宣布完成 4 亿美元 C 轮融资，未来资产领投，美团战投、合肥国投等政府平台、凯辉基金等跟投，高瓴创投、五源资本、淡马锡旗下 Vertex Growth、Prosperity7（沙特阿美）等老股东加码。成立约两年累计融资约 8 亿美元（A 轮 1 亿 → B1 1.2 亿 → B2 1.5 亿 → C 轮 4 亿）。公司定位"卖铲人"：不做机器人本体，提供计算芯片 + 算法 + 开发平台的软硬一体底座。2026 上半年营收同比增长数倍，旭日系列芯片累计出货突破 800 万片；2025 年 11 月发布的旭日 S600 半年内拿下它石智航、千寻智能、自变量机器人、优必选、帕西尼感知、北京人形机器人创新中心等 20 余家头部客户，具身智能领域客户覆盖率突破 50%，多数项目已进入量产级出货。

Why it matters：这是具身智能"基础设施层"成为独立资本叙事的标志性事件：本体厂商还在为谁能量产厮杀，地瓜已经把"无论谁赢都要买芯片和工具链"的位子占住了——50% 客户覆盖率意味着它接近成为下游的默认选项，类似具身领域的"高通 + 英伟达开发套件"复合体。对观察行业的人，两个先行指标值得记录：(a) 融资斜率（两年 8 亿美元、单轮 4 亿为赛道头部级别）说明资本明确在从"本体故事"向"确定性更强的上游"迁移；(b) 出货量（800 万片）说明具身智能的钱正在流向"数据采集-训练-仿真-部署"全链路，而非只堆叠人形样机。当基础设施完成规模化验证，本体厂商的比拼会进一步聚焦在大模型能力与场景订单上。
